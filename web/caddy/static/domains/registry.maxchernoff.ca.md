This is a container registry for various projects. All images are signed
with the Cosign public key available at
[`/key.pub`](https://registry.maxchernoff.ca/key.pub), and the full list
of images is available at
[`/v2/_catalog`](https://registry.maxchernoff.ca/v2/_catalog).
